Concept · images are layers

Order your Dockerfile for the cache

COPY . . ← changes often: last
RUN npm ci ← reused while package*.json is unchanged
COPY package*.json ./
WORKDIR /app
FROM node:24-alpine
A change invalidates its own layer and every layer above it. Code last, dependencies first.

Concept · hardening, verified

Not "should be secure": checked

$ docker inspect … user / read-only / capabilities proxy: user=nginx read-only=true cap_drop=[ALL] cap_add=[] frontend: user=nginx read-only=true cap_drop=[ALL] cap_add=[] api: user=nonroot:nonroot read-only=true cap_drop=[ALL] cap_add=[] $ docker compose exec proxy sh -c 'echo hacked > /usr/share/nginx/html/index.html' sh: can't create /usr/share/nginx/html/index.html: Read-only file system $ docker compose exec api sh … exec: "sh": executable file not found in $PATH
From the capstone: non-root users, read-only file systems, no capabilities, no shell in the API, and the database password as a secret file, never an environment variable.
